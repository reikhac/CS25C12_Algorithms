COURSE PATHWAY

Learn in connected steps

Course pathway aligned to the uploaded CS25C12 syllabus. Confirm the current approved copy with the department before semester deployment.

Unit I

Foundations of Algorithm Analysis

Performance analysis; space complexity; time complexity; asymptotic notation: Big-O, Omega, Theta and little-o; recurrences; probabilistic analysis.

  • Assignment: time and space complexity calculation for a given logic; usage of loops, conditionals and mathematical principles.
Unit II

Divide & Conquer Methods

Merge sort; long integer multiplication; Strassen’s matrix multiplication; Master method; Job Sequencing Problem with Deadlines.

  • Flipped classroom: solving a puzzle; review of GATE questions.
Unit III

Greedy Methods and Dynamic Programming

Activity Selection Problem; Huffman Codes; fractional Knapsack; 0–1 Knapsack; Matrix Chain Multiplication; Optimal Binary Search Tree; Longest Common Subsequence.

  • Project-based experiential learning: creation of treasure hunt; quiz on state transition, recurrence relations and space optimization technique.
Unit IV

String Matching and Convex Hull Algorithms

Multithreaded algorithms; polynomial multiplication; Fast Fourier Transform; Extended Euclid Algorithm; Naïve algorithm; Rabin–Karp algorithm; Graham’s Scan; Jarvis March.

  • Assignment: Rabin–Karp algorithm; quiz on multithreaded and Euclid algorithms.
Unit V

Solvability and Tractability

Classes P and NP; NP-Hard and NP-Complete problems; Vertex Cover; Travelling Salesman; Set Covering; Subset Sum; N Queen; Graph Coloring; Hamiltonian Cycle; Assignment Problem; Knapsack Problem.

  • Assignment: approximation and randomized algorithms; review of GATE questions.
Unit VI

Network Flow Algorithms

Flow networks; maximum flows: Ford–Fulkerson, Edmond–Karp, Push–Relabel, Relabel-to-front; minimum cost flows; Cycle Cancelling Algorithm.

  • Flipped classroom: Relabel Algorithm; review of GATE questions.
